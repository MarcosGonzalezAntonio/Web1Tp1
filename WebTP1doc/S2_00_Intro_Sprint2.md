# Sprint 2: MiEcommerce Interactivo

## 🎯 Objetivos
Agregar el código de programación JS necesario para que nuestro prototipo funcional evolucione en una aplicación interactiva con funcionalidades, datos y comportamientos reales.

## 🔧 Requisitos Técnicos
- Computadora con Node.js instalado.
- Conexión a internet.
- Repositorio Git para control de versiones.

## 🚨 Pautas de Desarrollo
- **Progreso Individual:** Cada miembro del equipo debe producir una parte significativa del proyecto.
- **Trabajo Colaborativo:** Aplicar metodologías aprendidas para el avance conjunto y división de tareas.
- **Buenas Prácticas:** Código Javascript correcto, completo, ordenado, elegante y siguiendo el patrón MVC.
- **Funcionalidad:** El producto final debe cumplir con todos los requisitos funcionales detallados en las User Stories.

## 📦 Entregable
Un repositorio Git con el código producido. Se valorará positivamente el uso de ramas (branching) para organizar las funcionalidades.

## 🗒️ Resumen del Sprint
En este sprint, pasaremos de un prototipo estático a una aplicación funcional. Nos enfocaremos en:
1. **Datos Reales:** Mostrar información desde archivos JSON en listados y detalles de productos.
2. **Carrito de Compras:** Implementar lógica de persistencia y gestión de productos seleccionados.
3. **Sesiones y Persistencia:** Administrar el estado de la aplicación usando `express-session`.
4. **Arquitectura MVC:** Estructurar el proyecto separando Modelos, Vistas y Controladores para una mejor mantenibilidad.
5. **API Rest:** Implementar una API para consumir datos de forma segura.
